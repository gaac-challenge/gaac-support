昇腾

华为的 AI 芯片系列及其整机、软件栈,出口管制下中国推理算力的主力

与主线一 KV cache · 强HBM 受限,华为把 KV cache 外推到 DRAM、SSD 与专用存储(UCM、KV Pool)与主线二 Agent 负载 · 中华为用 agent 的长上下文解释 950PR 与 KV 存储层的设计,但没有 agent 专属产品

它是什么

昇腾(Ascend)是华为的 AI 处理器品牌。图里的"昇腾"指的是一整套东西:芯片(Ascend 910B、910C、950 系列等,华为称之为 NPU,即神经网络处理器);装着这些芯片的 Atlas 服务器和"超节点";以及让模型能在上面跑起来的软件栈(CANN、MindSpore、MindIE、vllm-ascend 等)。

它要解决的问题很直接:美国出口管制让中国公司买不到 NVIDIA 的先进 GPU,华为也无法在台积电流片,中国需要一套在国内能造、能买到的 AI 算力。华为自己承认单颗芯片落后。2025 年华为全联接大会上,时任轮值董事长徐直军回顾前一年的判断:中国半导体制造工艺将在相当长时间处于落后状态,可持续的算力只能基于实际可获得的工艺一手徐直军 2025 主题演讲。华为的对策是把大量芯片用自研高速互联连成一台逻辑上的大机器,也就是"超节点 + 集群"路线。

来历与时间线

  • 2018 年发布 Ascend 310(端侧/边缘推理),2019 年发布 Ascend 910(数据中心训练)一手(徐直军演讲)。
  • 910B、910C 是制裁之后转到国内工艺的后续型号,制程与代工厂华为从未公布未复核。
  • 2025 年初 DeepSeek 爆红。徐直军说华为云为接住流量,研发团队从春节做到 2025-04-30,才使 Ascend 910B/910C 的推理能力达成客户的基本需求一手(同上)。
  • 2025 年 3 月,Atlas 900 超节点上市,满配 384 颗 910C,最大算力 300 PFLOPS。常听到的 CloudMatrix384 是华为云基于 Atlas 900 构建的云服务实例一手(同上)。
  • 2025-08-05 昇腾产业峰会:华为宣布坚持硬件变现;CANN 的编译器和虚拟指令集接口开放、其余软件全开源;Mind 系列使能套件和工具链全面开源,均承诺在 2025-12-31 前完成一手(同上)。
  • 2025-08-12 发布 UCM(推理记忆数据管理器),2025 年 11 月开源二手鉅亨網。
  • 2025-09-18 首次公布芯片路线图(见下节)。
  • 2026 年上半年:950PR 量产,报道的时间在 3–4 月之间二手。2026-04-24 DeepSeek V4 发布,华为同日宣布昇腾 950 与 A3 超节点完成适配二手科技日报。
  • 2026-09-17 全联接大会 2026:轮值董事长汪涛更新路线图(见"现状")二手每日经济新闻。

它做了什么

芯片代际与路线图

报告提到的"华为 2025-09 公布 950/960/970 路线图"经核实属实,出自徐直军演讲原文一手:

芯片 计划时间(2025 年版) 定位与要点
Ascend 950PR 2026 Q1 面向推理 Prefill 阶段和推荐;用自研低成本 HBM HiBL 1.0
Ascend 950DT 2026 Q4 面向推理 Decode 阶段和训练;自研 HBM HiZQ 2.0,内存 144GB,访存带宽 4TB/s
Ascend 960 2027 Q4 算力、内存、带宽等规格相比 950 翻倍;支持自研 4bit 格式 HiF4
Ascend 970 2028 Q4 规格在讨论中;FP4/FP8 算力和互联带宽相比 960 翻倍

950PR 和 950DT 用的是同一颗计算芯片(Ascend 950 Die),区别只在合封的内存。950 新增支持 FP8、MXFP8、MXFP4 等低精度格式和华为自研的 HiF8,FP8 算力 1 PFLOPS、FP4 算力 2 PFLOPS,互联带宽 2TB/s一手。Prefill 是模型读入全部输入的阶段,吃算力但不太吃内存带宽;Decode 是逐个吐出 token 的阶段,吃内存带宽。把一代芯片按这两个阶段拆成两个型号,是华为针对 HBM 短缺做的设计。950PR 的内存规格(128GB、1.6TB/s)演讲文字稿没有写,来自媒体对幻灯片的转述二手。

整机:Atlas 与超节点

  • Atlas 800 系列服务器:8 卡推理/训练服务器。开源社区用 A2、A3 指代搭载 910B、910C 的两代机型未复核。
  • Atlas 900 超节点 / CloudMatrix384:384 颗 910C 通过灵衢(UnifiedBus,华为自研的超节点互联协议)连成一台机器。华为论文称在其上运行 DeepSeek-R1 可达每颗 NPU 每秒 538 token(每 token 延迟 15 毫秒以内)厂商自述,仅摘要arXiv 2506.12708。
  • Atlas 950 超节点:2025 年宣布的满配规格是 8192 张 950DT 卡、160 个机柜、内存 1152TB,计划 2026 Q4 上市。华为称其规模是 NVIDIA NVL144 的 56.8 倍、总算力 6.7 倍厂商自述(徐直军演讲)。这是把几千颗较弱的芯片与一个机柜的强芯片相比,不是单芯片对比。

软件栈

  • CANN:昇腾的底层计算架构,地位相当于 NVIDIA 的 CUDA 加 cuDNN,包含算子库、编译器和运行时。
  • MindSpore(昇思):华为自研的深度学习框架。实际推理部署更多经由 PyTorch 适配层 torch_npu。
  • MindIE:华为自己的推理套件。vllm-ascend 文档建议生产环境使用 MindIE Motor 加 vLLM-Ascend 的组合仅摘要。
  • vllm-ascend:vLLM 社区的昇腾硬件插件。稳定版 v0.30.0 发布于 2026-10-29,对齐上游 vLLM v0.30.0,依赖 CANN 9.2.1、torch_npu 2.10.0,重点模型是 DeepSeek V4.1、GLM-5.3、Qwen3.8-27B、Kimi K3一手vllm-ascend release notes。报告记录的 vLLM 主线是 v0.34.0,插件线落后几个小版本。
  • AMCT:CANN 的模型压缩工具,2025-12-22 在 GitCode 开源。支持 INT8、INT4、MXFP8、MXFP4 和 HiFloat8 量化,算法含 AWQ、GPTQ、SmoothQuant;2026-04-24 加入 DeepSeek-V4 的 INT8 量化,2026-10-20 加入面向 950 的 DeepSeek-V4.1 HiFloat8 权重导出一手AMCT README。

2026 年的现状

  • 路线图加速:汪涛在 2026 年大会上称 960DT 提前三个季度到 2027 Q1、960PR 到 2027 Q3,970 和 980 分别在 2028、2029 年推出;910C 超节点累计部署超过 1000 套,950 超节点已规模商用;昇腾 960 超节点单节点 4096 颗 NPU、最大 8 EFLOPS(FP8)二手(每日经济新闻)。
  • 产量与收入:Tom's Hardware 转述称,华为预计 2026 年 AI 芯片收入约 120 亿美元(2025 年为 75 亿),依据是阿里、字节、腾讯等已下的订单,950PR 是这些公司的主要采购目标二手Tom's Hardware。研究机构 Epoch AI 估计 2026 年昇腾总产量约 150 万颗(其中 950PR 75 万、910C 43 万、950DT 32 万),折算算力不到 NVIDIA 同年的 4%,芯片性能落后三到四年二手,模型估算Epoch AI。
  • 制程与 HBM:Epoch AI 称 950/960 的计算芯片据报用中芯国际 N+3 工艺;910C 主要靠囤积的三星 HBM2E;长鑫存储的 HBM 在 2026 年初产量有限;并推断 950PR 用的可能不是真正的 HBM,而是接近 LPDDR 的内存二手,推断。华为只说是"自研低成本 HBM",未披露制造方。
  • 谁在用:华为云自用;徐直军称 Atlas 900 到 2025 年 9 月服务 20 多个客户,涵盖互联网、电信、制造一手;汪涛称昇腾超节点客户已超过 370 家二手。DeepSeek 在 V4 定价说明里称要等 950 超节点批量上市后 Pro 版才能大幅降价二手。互联网大厂的采购量没有公司公告,只有媒体报道。
  • 国产对手:寒武纪是最接近的上市对手,2026 年前三季度营收 95.26 亿元、归母净利润 37.15 亿元二手,转述其三季报东方财富,量级明显小于华为的 AI 芯片收入预期。DeepSeek V4 发布当天,寒武纪、海光、摩尔线程、沐曦等都宣布完成适配二手。昇腾和寒武纪都没有公开的独立推理基准。

与主线一(KV cache)的关系

关系强,而且方向和 NVIDIA 生态一致,动机更迫切:HBM 是昇腾最紧的供给约束,KV cache 又恰好占用 HBM。

  • 芯片层:950PR 的设计前提是"通过分级内存解决方案,Prefill 阶段对本地内存容量的需求相对不高",所以可以配便宜的内存一手(徐直军演讲)。这等于在芯片规格里默认 KV cache 不会全留在卡上。
  • UCM(Unified Cache Manager):报告笔记里"归属和功能未核实"的 UCM 已核实,是华为系的开源项目(GitHub 组织 ModelEngine-Group)。它是夹在推理引擎和存储之间的 KV cache 管理层,把可复用的 KV cache 持久化到外部存储,在请求之间、兼容的推理实例之间共享,以减少重复的 Prefill 计算;支持接入 vLLM、vLLM-Ascend 和 SGLang;支持矩阵列出昇腾 910B/910C/950PR/950DT 与 NVIDIA H100/H20/L40/L20。项目自称在前缀高度重复的场景下推理延迟降低 3–10 倍一手文档,倍数为厂商自述UCM 文档支持矩阵。950PR/DT 目前只用 DeepSeek-V4-Flash 和 GLM-5.2 验证过。
  • vllm-ascend 的 KV 特性:v0.30.0 的发布说明里与 KV 有关的条目很多,分两类。一类是把 KV 搬出卡外:KV Pool(KV 缓存池)支持按层存取、DRAM/SSD 两级的 memcache 池化、通过 Mooncake 传输;PD 分离部署时 KV 在 Prefill 节点和 Decode 节点之间传输。另一类是压缩卡上的 KV:INT8 打包 KV cache(C8)、MXFP8 KV cache、TurboQuant 4 bit 潜空间 KV cache(仅 A2/A3)一手(vllm-ascend release notes)。前缀缓存继承自 vLLM 上游;早期版本的搜索摘要显示混合注意力模型的前缀缓存出过静默输出错误并已修复仅摘要。
  • 存储层:汪涛在 2026 年大会上称,agent 场景下每张昇腾卡对应的 KV cache 可能达到 TB 级,HBM 和 DRAM 放不下,华为因此提出多层 KV 缓存架构,发布通过灵衢直连计算芯片的 PB 级 KV 缓存产品 OceanStor M900二手,厂商自述(每日经济新闻)。华为企业存储官网把"无法持久化 KV Cache 导致大量重复计算"列为推理贵的原因一手华为 AI 推理加速方案。

综合来看,昇腾这一侧把主线一的四个层级都做了对应物:卡上内存(并做 KV 量化)、主机 DRAM、SSD、网络存储(M900)。但效果数字全部是厂商自述,没有第三方测量。

与主线二(Agent 负载)的关系

关系中等。华为在叙事层面反复用 agent 解释硬件设计,但没有查到面向 agent 的专属产品或基准。

  • 徐直军解释为什么要单独做 950PR 时说,随着 Agent 的快速发展,输入上下文越来越长,首 Token 输出阶段占用的计算资源越来越多一手。这把"agent 导致 Prefill 变重"直接写进了芯片分型的理由。
  • 汪涛 2026 年的说法是 agent 任务持续时间变长、上下文到百万 token 级、与模型的交互频次高于人机问答,所以需要外置 KV 缓存层二手。
  • UCM 文档把多轮对话、编码、多 agent 协作列为前缀反复出现的典型场景一手。
  • 没有查到的:昇腾侧针对 agent 会话的调度、会话亲和路由或 agent 基准成绩。这些能力在这套栈里由上层的 vLLM 和编排系统承担,不属于昇腾本身。

与图中其他概念的关系

  • vLLM:最强的一条关系。vllm-ascend 是 vLLM 官方组织下的硬件插件,昇腾上跑开源大模型的主要通道。
  • Mooncake:vllm-ascend 依赖 mooncake-transfer-engine-npu(0.3.14-rc1),KV Pool 和 PD 分离用 Mooncake 做 KV 传输一手。
  • SGLang:UCM 提供 SGLang 接入路径一手;SGLang 自身对昇腾芯片的支持情况未查。
  • llm-compressor:AMCT 是它在昇腾上的对应物,两者不通用;量化产物必须匹配芯片代际(A3 用 INT8,950 用 MXFP8/MXFP4/HiFloat8)。
  • EAGLE-3:vllm-ascend 发布说明多处提到投机解码与 MTP 草稿模型;是否支持 EAGLE-3 本身未确认仅摘要。
  • Vera Rubin NVL72:华为把 Atlas 950 超节点与 NVIDIA 同代机架产品对标厂商自述;两者市场因管制基本隔离。
  • Cerebras、AMD Helios、TPU Ironwood:同层的其他非 NVIDIA 算力,没有直接往来。
  • 与 OpenRouter、LiteLLM、MCP、Open Responses、AA-AgentPerf、llm-d、GIE、KServe、Dynamo、AIBrix、TensorRT-LLM、llama.cpp、MNN、GGUF、ExecuTorch、LiteRT 没有查到实质关系。

存疑与未核实

  • 报告引用不匹配:报告称"二手报道称长鑫的 HBM 只够 25–30 万颗 Ascend 910C",引用 TrendForce 一篇文章。我打开该链接,内容是中国把华为、寒武纪芯片列入政府采购清单,没有这个数字;另行搜索也没找到出处。这个说法应视为未证实。
  • 笔记中的路线图日期:笔记写 950PR 在 2026 Q1、950DT 在 2026 Q4,与华为原文一致。950DT 是否已按期上市,没有查到确认。
  • Atlas 960 规格前后不一:2025 年演讲说 Atlas 960 超节点最大 15,488 卡;2026 年媒体报道的昇腾 960 超节点是 4096 颗 NPU。可能是产品定义变了,也可能是不同配置,未核实。同理,2026 年 7 月展出的 Atlas 950 是 1024 卡真机,8192 卡满配是否交付未知二手。
  • 部署套数口径:"超过 1000 套"在不同媒体里分别指 910C 超节点和全部昇腾超节点。
  • 华为 2026 年大会的官方演讲稿没有找到,相关内容全部来自媒体转述(每日经济新闻全文已读)。
  • 950PR 是否使用真正的 HBM、由谁制造、中芯国际的制程与良率,全部是分析机构推断。
  • 字节、阿里、腾讯的采购金额只有媒体报道;"华为称 DeepSeek V4 部分训练使用昇腾"也只见于报道。
  • DeepSeek V4 在 950 超节点上的单卡吞吐数字在搜索摘要里自相矛盾(Pro 版高于 Flash 版),本文未采用。
