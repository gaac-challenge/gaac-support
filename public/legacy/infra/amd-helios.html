AMD Helios

AMD 首个机架级 AI 系统:72 颗 MI455X 的开放标准液冷机架

与主线一 KV cache · 中每机架 31 TB HBM4 是卖点,但未见与 CMX 对等的 KV 存储层与主线二 Agent 负载 · 中以 agentic AI 时代为题,论据主要在 CPU,无第三方 agent 基准

它是什么

Helios 是 AMD 第一次以「整机架」而不是「芯片」为单位出售的 AI 系统。在此之前,AMD 卖的是 Instinct GPU 和 EPYC CPU,由服务器厂商和云厂商自己装成 8 卡服务器再拼集群;NVIDIA 则从 2024 年起以 NVL72 整机架交付。Helios 是 AMD 对这种交付形态的回应:一个液冷机架里装 72 颗 Instinct MI455X GPU、18 颗第六代 EPYC「Venice」CPU,加上 AMD Pensando 的前端、scale-up(机架内 GPU 互连)与 scale-out(机架间互连)网络,以及 ROCm 软件栈一手AMD AAI 2026 新闻稿。

它与 NVIDIA 方案的主要差别在「开放」:机架采用 AMD 与 Meta 通过 Open Compute Project(OCP,开放计算项目)共同开发的 Open Rack Wide 规格,GPU 互连跑在以太网上而不是私有的 NVLink,交换芯片来自 Broadcom,网络操作系统是开源的 SONiC二手StorageReview。

来历与时间线

  • 2025-03-31:AMD 完成对 ZT Systems 的收购。ZT 是为超大规模云厂商设计和制造机架级服务器的公司;AMD 明确说只要它的设计团队(并入 Forrest Norrod 领导的数据中心方案事业部),制造业务要另找买家一手AMD 新闻稿。收购价 49 亿美元;制造业务于 2025 年 10 月卖给 Sanmina,后者成为 AMD 机架级方案的首选新品导入制造伙伴二手,仅摘要。这笔交易的作用就是让 AMD 具备「设计整机架」的能力,Helios 是它的第一个产物。
  • 2025-10-06:AMD 与 OpenAI 宣布多代协议,最多 6 GW 的 Instinct GPU,首个 1 GW 的 MI450 于 2026 年下半年开始部署;AMD 向 OpenAI 发放最多 1.6 亿股、行权价 0.01 美元的认股权证,按部署里程碑与股价门槛分批归属二手,仅摘要Tom's Hardware。
  • 2025-10-14:Oracle 宣布自 2026 年第三季度起部署 5 万颗 MI450,采用 Helios 机架仅摘要Oracle 新闻稿。
  • 2026-02-24:AMD 与 Meta 宣布最多 6 GW 的多代协议,首个 1 GW 的出货定于 2026 年下半年,使用基于 MI450 架构的定制 GPU;同样附带最多 1.6 亿股的业绩型认股权证一手AMD newsroom。
  • 2026-07-22:AMD 与 Anthropic 宣布最多 2 GW 的 MI450 系列(Helios 机架),首个 1 GW 于 2027 年上半年开始部署;AMD 承诺「未来」向 Anthropic 作最多 50 亿美元的战略股权投资,未列条件;Anthropic 此前已在用 MI355X一手AMD 新闻稿。
  • 2026-07-23:Advancing AI 2026 大会,AMD 称 Helios「现已投产」一手。

它做了什么

硬件组成

以下为 StorageReview 根据 AMD 发布材料整理的参考设计规格,客户实际部署可以不同二手StorageReview:

项目 数值
GPU 72 颗 MI455X,分装在 18 个四卡计算托盘
单 GPU 显存 432 GB HBM4(12 个堆叠)
机架 HBM4 31 TB,带宽约 1.7 PB/s
CPU 18 颗 Venice(参考配置 96 核,可换至 256 核)
主机内存 每托盘 1 TB DDR5,可扩至 4 TB
scale-up 每 GPU 3.6 TB/s,UALink over Ethernet
scale-out Pensando Vulcano 800GbE 网卡,Ultra Ethernet
前端 每托盘一颗 Pensando Salina 400G DPU
功耗 225–245 kW,液冷

几个名词:MI455X 是 MI450 系列的旗舰型号,计算核心用台积电 N2 工艺;UALink 是多家厂商组成联盟制定的开放 GPU 互连标准,AMD 在 Helios 上把它跑在以太网物理层上(称 UALoE);Pensando 是 AMD 2022 年收购的网络芯片业务。AMD 自己的宣传册对单 GPU 内存带宽、机架内存带宽给出的数字与上表略有出入(搜索摘要中见到 19.6 TB/s、1.4 PB/s 等),未能统一仅摘要。

厂商性能说法及其条件

  • 比 Vera Rubin NVL72 每美元多 30% token:脚注注明是 AMD 实验室 2026 年 7 月的估算,负载为 Kimi K2 Thinking、32K 输入/8K 输出,取低中高三个交互速度点的合计吞吐,再配上「预计的」GPU 小时价格厂商自述。当时 AMD 手里并没有可供对测的 Rubin 机架。
  • MI455X 的 token 吞吐为 MI355X 的 34 倍:AMD 实验室测量加计算,DeepSeek V4 Flash、FP4 精度厂商自述。
  • StorageReview 提醒:AMD 的 MXFP4 与 NVIDIA 的 NVFP4 是两种不同的 4 比特格式,跨厂商的 FP4 算力不可直接比较;实测持续 FP4 算力约为标称峰值 40 PFLOPS 的一半二手。

软件栈 ROCm

ROCm 是 AMD 对标 CUDA 的开源 GPU 软件栈,长期被认为是 AMD 的短板。2026 年能确认的进展:新闻稿称 PyTorch、Hugging Face、vLLM 与 SGLang 已在 MI455X 上可用,并推出 ROCm.ai(面向 Claude、Codex、Cursor 等编码 agent 的 GPU 开发平台)厂商自述;AMD 自称 ROCm.ai 相对 ROCm 7 在同样硬件上推理平均提升 3.3 倍厂商自述,二手转述;MLPerf v6.1 中,同一台 8 卡 MI355X 节点仅靠 ROCm v7 软件更新,gpt-oss-120B 吞吐在一个周期内提高 28%(离线)与 38%(服务器)二手StorageReview MLPerf 综述;第三季度又发布了 ROCm 10二手。Anthropic 协议里专门有一项是用 Claude 加速 ROCm 开发,OpenAI 则在把自家的 Triton 与 ROCm 做全栈优化一手。软件在快速改进,但「快速改进」本身也说明它还没到位。

客户 规模 首批时间 来源等级

独立证据方面,Helios 目前是空白:MLPerf v6.1 没有 MI455X 或 Helios 的提交,AMD 的结果全部来自上一代 MI355X/MI350(包括 Crusoe 的 512 卡集群);AA-AgentPerf 里的 AMD 系统也只有 8 卡 MI355X,且配置由 Artificial Analysis 自己搭建而非 AMD 调优一手AA-AgentPerf。路线图上,2027 年为 MI500 与 Helios 500(配 EPYC Verano),2028 年为 MI600一手。

与主线一(KV cache)的关系

关系中等,集中在「HBM 容量」这一个机制上。

  • 容量:单 GPU 432 GB HBM4,比 Rubin 的 288 GB 多 50%;机架 31 TB 对 20.7 TB。对同一个模型,权重占用固定,多出来的显存基本都能给 KV cache,意味着单卡可以容纳更多并发会话或更长上下文而不必把 KV 逐出到主机内存。这是 AMD 自 MI300 以来一贯的差异化打法。代价是每颗 GPU 要用 12 个 HBM4 堆叠,而 HBM4 正是 2026 年最紧缺的部件——AMD 与 Anthropic 新闻稿的风险提示里就列了内存供应一手。
  • 下一层:每个计算托盘 1–4 TB DDR5 主机内存,可作 KV 卸载层。但 Venice 到 MI455X 的主机链路为 256 GB/s,远窄于 Vera 到 Rubin 的 1.8 TB/s,KV 在显存与主机内存之间换入换出会更慢二手,StorageReview 的比较。
  • 存储层:StorageReview 提到 Salina DPU 带有「KV-cache offload engine」,但同时指出 Helios 没有 GPUDirect Storage 的对等物,存储流量要经过主机 CPU二手。本次没有读到 AMD 发布与 NVIDIA CMX 对等的、专门存 KV 的 pod 级闪存层;Helios 上的 KV 分层目前要靠 vLLM、SGLang 等引擎层软件。
  • CXL:本次读到的 Helios 材料里没有出现 CXL 内存扩展的说法未复核。

与主线二(Agent 负载)的关系

关系中等偏弱:口号很强,机制和证据偏弱。

  • 发布会新闻稿标题就是「为 Agentic AI 时代提供全栈算力」,Lisa Su 的原话是下一阶段的 AI 将「跨越前沿模型、agent 与物理 AI」厂商自述。
  • 但 agent 相关的具体论据主要落在 CPU 上:AMD 称第六代 EPYC 能做到「每瓦、每美元、每机架最多的 agent」,脚注是在 100 kW 机架包络下与 88 核的 NVIDIA Vera 机架比核心数(256 核的 EPYC 9996 为 2.08 倍),并写明「agent 数量是代理估算」厂商自述。这与 NVIDIA 用 Vera CPU 机架讲 agent 沙箱是同一套叙事的两面:agent 的工具执行跑在 CPU 上,所以 CPU 核心密度成了卖点。
  • Helios GPU 机架本身的宣传指标仍是每美元 token 与吞吐,没有针对多轮会话、前缀复用的专门设计。
  • 第三方 agent 基准没有测过 Helios(见上)。Zuckerberg 对 Meta 协议的表述是「部署高效的推理算力」,未提 agent一手。

它出现在图里的理由主要是产业结构:它是 2026 年唯一拿到多家头部实验室吉瓦级承诺的非 NVIDIA 商用 GPU 机架,决定了推理软件栈必须面对异构硬件。

与图中其他概念的关系

  • Vera Rubin NVL72:直接对标,同为 72 GPU 液冷机架,AMD 的性能声明以它为基线。
  • vLLM、SGLang:AMD 称两者已在 MI455X 上可用;Helios 没有自带的 KV 存储层,分层要靠这类引擎。
  • Cerebras:AMD 新闻稿提到与 Cerebras 合作,把 Helios 与其系统组合用于超低延迟推理一手。
  • AA-AgentPerf:只测了上一代 MI355X。
  • TPU Ironwood:共享客户 Anthropic;另据 The Next Platform,Google 的 TPU 8tx 变体改用 AMD EPYC 作主机 CPU二手。
  • 昇腾:无直接关系。

存疑与未核实

  • 报告称 AMD 宣称「每美元 token 最高 18 倍」。AMD 2026-07-23 新闻稿及其脚注里没有 18 倍这个数字,有的是 34 倍吞吐(对 MI355X)与 30% 每美元 token(对 Rubin);18 倍只见于二手媒体,未能核实出处。
  • 报告把 Helios 写成「7 月发布」。7 月是宣布投产并公布完整规格;Helios 的首次预告更早(2025 年),OpenAI、Oracle、Meta 的协议也都早于 7 月。
  • 「约 14 GW 已预订」是媒体加总,不是 AMD 原话。
  • AMD 第三季度财报原文未能打开,客户上线情况来自 JPR 转述;MI455X 的实际出货量无数据。
  • AMD 官网的 MI400 产品页与 Helios/Meta OCP 博客均连接超时,Open Rack Wide 的细节与 31 TB 的官方出处靠 StorageReview 与搜索摘要中的 AMD 宣传册。
  • Meta 协议总金额在二手报道中有 600 亿与 1000 亿美元两种说法,AMD 新闻稿未给金额。
